# NBA znalostní báze

Spravuje ji agent `nba-expert` (`.claude/agents/nba-expert.md`).

- `teams/<ZKRATKA>.md` — soupiska a stav týmu (např. `BOS.md`, `LAL.md`)
- `transactions.md` — log přestupů, výměn, podpisů a uvolnění (nejnovější nahoře)
- `news.md` — přehled posledních důležitých zpráv

Každý soubor má v hlavičce `Aktualizováno: RRRR-MM-DD` a zdroje.
